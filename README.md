# AI Shopping Cart

A Java command-line shopping cart built with Spring Boot, Spring AI, MySQL, and Google Gemini for natural-language cart management.

## API Key

Add your Gemini API key to `GEMINI_API_KEY.txt`, replacing the placeholder.

Get a key from [Google AI Studio](https://aistudio.google.com/api-keys).

## Run

Requires Docker. From the project directory:

```bash
./run.sh
```

At the `cart>` prompt, use `help` to see available commands or `ai MESSAGE` to interact with Gemini.
